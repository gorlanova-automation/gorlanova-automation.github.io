# Портфолио Елены Горлановой

Статический сайт-портфолио по автоматизации, AI-инструментам и vibe coding.

## Локальный просмотр

Откройте `index.html` в браузере. Сборка и серверные зависимости не требуются.

## GitHub Pages

Репозиторий должен называться `<organization>.github.io`. После публикации сайт будет доступен по адресу `https://<organization>.github.io/`.
